Sheet A · Motors and power, soldered

Solder each motor's two leads to the pin tails on the underside of the board. Numbers 1–8 are the eight motor joints, 9–10 the motor power.

Sheet B · Logic wires, plugged in

Fourteen plug-in jumper wires from the Nucleo's morpho pins to the RBT01's 40-pin socket. Same signals as before; the front direction wires now come straight from the Nucleo.

Before power, then firmware setup

Do these in order with the wheels off the ground. Commands go over the Nucleo's USB serial port (COM7, 115 200 baud), from the web serial tool or any terminal. Each command keeps a wheel turning for about 1.5 s, then the firmware stops it by itself.

1 · Meter checks, no power

  • Across one motor's two pins: a few ohms (the winding). It may flicker as the shaft turns.
  • Middle pair of each block, 1B ↔ 1A: not a short.
  • Any motor pin ↔ GND: open.
  • CN3 + ↔ GND: not a short. The reading climbs as the 330 µF capacitor charges.
  • CN3 GND ↔ CN2 pin 6: beeps. CN2 pin 1 ↔ pin 17: beeps (both 3V3).
  • Mode jumpers: J6 1-2, J7 2-3, J8 1-2, J11 1-2, J12 2-3, J13 1-2.

Then power up in this order: Nucleo USB first, then motor power at 7.4–9 V with a 1 A current limit.

2 · Set every wheel's direction

Start from a known state. FLIP:n,1 is the default direction that matches the soldering rule.

3 · Whole rover, then save

FORWARD       all four roll forward
BACKWARD      all four roll backward
RIGHT         spins clockwise, seen from above
STRAFE:40     slides to the right
SAVE          reply OK:SAVED, kept after power-off
  • Slides left on STRAFE:40: send SFLIP:1.
  • Twists instead of sliding: the mecanum wheels are on the wrong corners. Swap the two front wheels with each other and the two rear wheels with each other.
  • Same way both times (the old front-wheel fault): meter that motor's direction pin on CN2 to GND while you send MOTOR:n,30 then MOTOR:n,-30. Pins: M1 = 23, M2 = 24, M3 = 19, M4 = 21. It must switch between 0 V and 3.3 V. If it stays at 0 V, the driver's internal pull-down is winning because the wire isn't connected: re-seat it on the Nucleo (CN7-38, CN7-36, CN7-35, CN7-37).

Signal chain: STM32L073RZ TIM3 CH1–CH4 (PC6 / PB5 / PB0 / PB1) for speed, PC0–PC3 for direction, PC4 / PC5 / PC9 / PC8 for enable → RBT01 CN2 → STSPIN948 U2 (M1, M2 → CN4) and U3 (M3, M4 → CN5). Motor power → CN3. Forward with the default settings drives the 2 pin high, so current enters each motor's black lead.
